ADR-003: Embedding WebView via JNA

Aceito • 2026-05-16

Contexto

Precisamos chamar funções C do GTK3 + WebKitGTK 4.1 a partir do Java. As opções: JNI (clássico), JNA (runtime reflection), ou Project Panama (JDK 22+).

Decisão

Usar JNA 5.14+ para todos os bindings nativos.

Bindings necessários (total ~100 linhas):
  • GTK3: gtk_init, gtk_window_new, gtk_container_add, gtk_widget_show_all, gtk_main, gtk_main_quit, g_signal_connect
  • WebKitGTK: webkit_web_view_new, webkit_web_view_load_html, webkit_web_view_load_uri

Justificativa

  • JNA: 1 dependência (com.sun.jna:jna:5.14.0), zero código C, zero compilação nativa
  • JNI: exige escrever header C, compilar .so, linkedição separada, mais pontos de falha
  • Panama: JDK 22+ necessário, documentação escassa, poucos exemplos de bindings GTK

Consequências

Positivas: Desenvolvimento rápido, zero compilação nativa, documentação JNA madura.
Negativas: JNA + GraalVM native-image precisa de config extra (jni-config.json). Erros de tipo em runtime viram segfault sem stack trace Java.
