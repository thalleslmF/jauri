ADR-005: Frontend HTML puro

Aceito • 2026-05-16

Contexto

Qual tecnologia usar pra construir a interface do usuário dos apps Jauri.

Decisão

O Jauri engine não impõe framework frontend. A engine serve arquivos HTML/CSS/JS estáticos. Cada app pode usar: vanilla, React, Svelte, Alpine.js, htmx, ou qualquer coisa que compile pra HTML/CSS/JS.

Contrato entre engine e app:
  • App coloca arquivos em src/main/resources/static/
  • Engine extrai pra /tmp/jauri-XXXX/ e serve via HTTP
  • JS faz fetch('/api/invoke', {method:'POST', body: JSON.stringify({cmd, args})})
  • Engine devolve {"result": ...} ou {"error": "..."}

Justificativa

  • Escolha do framework é do app, não da engine
  • HTML/CSS/JS é o padrão universal de UI
  • Separação clara: engine não sabe de React/Svelte/Vue
  • Hot reload natural: só trocar o arquivo HTML e recarregar

Consequências

Positivas: Flexibilidade total, ecossistema web completo (CodeMirror, DataGrid, Chart.js), zero lock-in.
Negativas: App precisa saber HTML/CSS/JS básico. Não é zero-code.
